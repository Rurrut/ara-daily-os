# 체크리스트로 기록하기

왼쪽 아래 ☑ 버튼으로 체크리스트를 연다. 목록은 시간표 옆에 남아 있고, 항목을 끌기 시작하면 잠시 접혀 시간표 전체를 사용할 수 있다.

1. `＋ 할 일 추가`에서 이름과 카테고리를 고른다.
2. 항목의 이름 부분을 빈 실제 칸으로 끌어 놓는다. 기본은 도착한 10분 칸만 기록한다.
3. 여러 칸에 기록하려면 원하는 시작 칸에서 잠시 멈춘 뒤 이어서 민다. 다음 시간까지 이어지며 화면 위아래에서 자동 스크롤된다. 놓은 후 양끝 손잡이로 길이를 바꿀 수도 있다.
4. 이어서 뜨는 메뉴에서 집중·만족도와 완료 여부를 입력한다. 점수를 눌러도 메뉴는 닫히지 않는다.

항목 이름을 길게 눌러 끌면 세로 방향으로도 바로 이동할 수 있다. 체크리스트의 세로 스크롤과 구분하기 위한 동작이다.

시간 범위를 먼저 선택한 경우에는 컨텍스트 메뉴의 `‹ 돌아가기 → 체크리스트`에서도 기록할 수 있다. 다른 기록 위에는 덮어쓰지 않는다. 취소하거나 실제 칸 밖에 놓으면 기록하지 않는다.

완료 체크는 체크리스트와 연결된 기록의 점수 메뉴에서 모두 가능하다. 같은 할 일을 여러 시간대에 기록해도 그날의 완료 상태는 하나다. 완료를 해제해도 시간과 점수는 유지한다. 기록 삭제는 완료를 해제하지 않으며, 할 일 삭제도 과거 기록을 삭제하지 않는다.

목록은 매일 다시 사용하는 항목이고 완료 여부는 날짜별로 저장한다. 날짜는 기존 시간표와 같이 기상일 기준이다. 항목의 `⋯`에서 이름·카테고리 수정과 삭제가 가능하며, 이미 기록한 칸의 이름과 카테고리는 그대로 보존한다.

PC 앱에서는 오른쪽 과제 목록의 이름을 시간표의 실제 칸으로 끌 수 있고, 컨텍스트 메뉴에서도 체크리스트를 고를 수 있다. 기존 오른쪽 체크박스와 연결된 칸의 완료 체크는 같은 상태를 사용한다.

## 업데이트와 데이터

화면 버전 **2026102103**. Android 2.6·2.7은 PC에 연결한 뒤 설정 → 앱 업데이트 → PC에서 업데이트 확인 → 준비된 화면 다시 열기로 적용할 수 있다. PC도 새 실행 파일을 사용해야 새 연결 정보를 보존한다.

기존 과제·완료 날짜·기록은 그대로 읽는다. 새 기록에는 항목의 ID를 저장해 점수 변경, 분할, 이동, 길이 조절, 재실행과 PC 동기화 뒤에도 연결을 유지한다. 인접한 기록이라도 서로 다른 할 일이라면 합치지 않는다.

실제 브라우저에서 항목 추가, 드래그 기록, 점수 연속 입력, 완료 체크, 재실행 후 보존을 확인했다. 실제 Android 기기의 터치 감도와 PC·휴대폰 사이 실제 왕복 조작은 별도 확인이 필요하다.
