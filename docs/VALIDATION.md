# 확인한 범위와 남은 한계

2026-10-20 기준입니다. 테스트 숫자는 동일 조건의 중복 실행을 합산한 값이 아니라 각 검증 묶음의 결과입니다.

## 저장소를 준비하면서 다시 확인한 항목

- 정리된 소스에서 Windows 앱 빌드
- 모바일 DOM 대역 테스트 67개
- 고정 취침 회귀 시나리오 96개
- 식사 준비 추가 회귀 시나리오 10개: 계획 복사·카테고리·상세 입력, 기존 기록·계획 보존
- 정리된 소스에서 Android 2.7 빌드
- 모의 HTTP를 실제 Android 통신 클래스에 주입하는 노션 회귀 검사 16개

위 항목은 정리한 저장소의 소스에서 다시 실행해 통과했습니다. GitHub 자동 검사에서도 모바일 테스트와 Windows 빌드를 통과했습니다. 자동 검사 설정은 `.github/workflows/check.yml`에 있습니다.

## 이전 작업에서 확인한 항목

- PC 자체 테스트 243개 통과: 식사 준비 추가 2개를 포함한 일정, 기록, 편집, 보존, UI 및 연동 대역 검사
- 같은 입력 907건에 대한 C#과 JavaScript의 일정 결과 일치
- 이행도 회귀 검사 13개와 칸별 점수 표시 매핑 7개
- Android APK 서명 동일성, 화면 업데이트 서명 및 PC 다운로드 파일 해시
- 테스트 기록으로 만든 390px·320px 모바일 브라우저에서 칸별 세 점수 표시

907건 비교용 자료와 실험 중간 산출물은 개인 작업 폴더에 있어 이 저장소의 CI에 포함하지 않았습니다. 재현 가능한 기본 검사는 소스에 함께 둔 테스트를 사용합니다.

## 아직 확인이 필요한 항목

- Android 2.7을 실제 휴대폰에 설치한 뒤 10월 20일 기록의 노션 전송 성공 여부
- 당시 HTTP 400이 인증 갱신 거절인지 세션 만료인지에 대한 정확한 원인
- 기기별 절전·알림 권한·백그라운드 제한 아래의 실제 전달 시점
- 사용자별로 다른 루틴과 우선순위에 대한 일반화
- 서로 다른 기기에서 같은 범위를 동시에 편집하는 여러 실제 상황

Google Calendar 연동과 앱 내 AI 자동 분석은 구현된 기능으로 소개하지 않습니다. 노션 데이터베이스는 읽기와 기록 저장에 사용하며, 현재 PC·휴대폰 동기화를 대신하지 않습니다.
