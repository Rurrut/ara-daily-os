# 버퍼 순서 — 2026-10-21

지연을 회복하는 효과가 있는 단계만 사용한다. 취침 시각은 고정하고 실제 기록과 과거·현재 계획은 유지한다.

## 웨이트를 기록하기 전

1. 존2 앞 대기 단축. 1끼니 시작 후 최소 90분, 실제 식사 종료 후 최소 60분을 지킨다. 기본 최대 30분.
2. 존2·샤워 뒤 대기 단축. 식전 준비와 끼니 시작 간격을 지킨다.
3. 존2 → 2끼니 → 샤워 순서로 바꿔 쓸 수 있는 여유 사용.
4. 존2 앞 대기 잔량 재확인. 첫 단계와 합쳐 최대 30분이며 중복 계산하지 않는다.
5. **요거트 종료 후 취침까지 최소 30분을 남기며 여유 단축.** 기본 종료 후 여유 50분에서 최대 20분. 부족한 만큼만 쓰며 요거트와 3끼니를 유지한다.
6. 그래도 부족하면 3끼니·준비 제외 후 웨이트 당기기. 2끼니 시작부터 웨이트까지 최소 150분 유지.
7. 기존 요거트 버퍼. 남은 요거트→취침 간격을 추가 완화해 취침 전에 끝나면 유지하고, 그래도 맞지 않으면 요거트·준비 제외. 기본 요거트10분+준비10분.
8. 요거트를 제외한 뒤 남는 4끼니→취침 여유 단축. 실제 4끼니 종료 후 최소 120분을 지킨다.
9. 실제 지연 회복 효과가 있으면 존2 제외.
10. 웨이트 시간 단축. 기본 최소 30분 유지.

5단계의 ‘종료 후 30분’은 **3끼니를 빼기 전 우선 사용하는 버퍼의 한도**다. 이후 7단계의 기존 추가 완화·제외 동작과 구분한다.

## 웨이트를 기록한 뒤

이미 한 끼니·존2·웨이트는 되돌리지 않는다. 기존 요거트 버퍼와 4끼니 이후 취침 여유만 사용한다. 실제로 먹은 요거트는 제외하거나 이동하지 않는다.

## 공통 조건

- 끼니 시작 간격 최소 3시간.
- 2끼니 시작→웨이트 최소 2시간 30분.
- 실제 4끼니 종료 후 최소 2시간 휴식과 고정 취침이 동시에 불가능하면 충돌과 부족한 시간을 표시한다. 취침 표시를 미루지 않는다.
- 회복량은 전체 조건을 반영한 전후 차이로 계산한다. 단계별 최대 시간을 단순 합산하지 않는다.
