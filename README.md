# ARA Daily OS

**계획과 기록을 한 화면에서 관리하고, 실제 기록에 맞춰 남은 하루를 다시 조정하는 시간관리 프로그램.**

계획을 세워도 그대로 보내기는 어렵습니다. 한 가지 행동이 늦어지면 뒤의 계획도 다시 고쳐야 합니다. 실제로 무엇을 했는지 기록하고, 하루를 돌아보는 일기까지 따로 쓰려면 같은 내용을 여러 번 입력하게 됩니다.

ARA는 이 과정을 한 흐름으로 묶는 것을 목표로 만들고 있습니다.

**계획 → 간단한 행동 기록 → 남은 계획 조정 → 노션에 하루 기록 저장 → 회고와 AI 분석에 활용**

*실제 개인정보 대신 테스트용 기록을 넣은 모바일 화면입니다.*

## 왜 만들었나

제가 필요했던 건 예쁜 계획표 하나가 아니었습니다. 생활이 계획과 달라져도 그때마다 하루 전체를 다시 짜지 않아도 되는 도구가 필요했습니다.

- **계획표와 기록표를 따로 쓰는 번거로움:** 같은 시간표에 계획과 실제 행동을 위아래로 배치했습니다.
- **기록 자체가 귀찮아지는 문제:** 시작·정지 타이머 대신 지나간 시간을 드래그하고 카테고리와 점수만 고르도록 했습니다.
- **한 번 늦어지면 계획 전체를 수정해야 하는 문제:** 실제 식사·운동 기록을 기준으로 이후 계획을 조정하고, 비워 둔 대기 시간과 선택 활동을 버퍼로 사용합니다.
- **회고할 때 다시 기억을 더듬어야 하는 문제:** 같은 기록을 노션의 날짜별 페이지와 AI 참고용 JSON으로 저장합니다.

## 어떻게 다른가

일정을 넣는 데서 끝나거나, 지나간 시간을 기록하는 데서 끝나지 않도록 만들고 있습니다. 기록이 다음 계획의 입력이 됩니다.

예를 들어 식사가 늦어졌다면 이미 지나간 계획을 실제 기록에 맞춰 바꾸지 않습니다. 과거와 현재 계획은 남겨 두고, **그다음에 해야 할 행동만** 조정합니다. 고정한 취침 시각은 유지하고, 남은 여유 시간을 먼저 줄입니다. 여유가 부족하면 불가능한 조건을 숨기지 않고 표시합니다.

현재 자동 조정 규칙은 제 식사·운동 루틴에 맞춰져 있습니다. 누구나 자기 루틴과 우선순위를 설정하는 범용 플래너는 다음 목표입니다.

## 지금 되는 것

- 10분 단위 계획·실제 시간표, 여러 시간을 가로지르는 범위 선택
- 계획 행동을 실제 칸으로 복사, 블록 이동·길이 조절·삭제·되돌리기
- 카테고리와 파스텔 색상 관리, 집중·만족도 입력, 시작·종료 시각 기준 이행도
- 실제 행동에 따른 이후 계획 조정, 지나간 계획 보존, 고정 취침과 버퍼 계산
- Android에서 PC 없이 기록·계획 조정·카테고리 관리
- 같은 Wi-Fi의 PC와 동기화, 겹친 변경 확인, 앱 내부 QR 연결
- 노션 로그인과 저장 위치 선택, 기상일 기준 날짜별 기록 저장
- 노션 하위 페이지에 AI가 참고할 JSON 저장
- Android 알림, Windows 알림, 다크 모드, 서명된 화면 업데이트

AI가 앱 안에서 일기를 자동 작성하거나 분석하는 기능은 아직 없습니다. 현재는 분석에 활용할 기록을 저장하는 단계입니다. 노션 연동도 PC와 휴대폰의 양방향 동기화 서버로 사용하는 구조는 아닙니다.

## 만들면서 해결한 문제

기능을 추가한 이유와 해결 과정은 [개발 기록](docs/DEVELOPMENT.md)에 정리했습니다.

- 휴대폰에서 기록할 때 키보드가 시간표를 가림 → 드래그와 선택형 점수 입력
- PC가 꺼지면 계획 조정이 멈춤 → 휴대폰에도 일정 엔진과 로컬 저장 구현
- 늦은 기록을 반영하자 과거 계획까지 바뀜 → 과거 계획 보존과 미래 재계산 분리
- 4끼니가 늦어지자 취침 표시까지 밀림 → 고정 취침 표시와 조건 충족 계산 분리
- 노션의 400 응답을 인터넷 오류로 표시함 → 인증·세션·요청 오류 구분과 제한된 세션 복구

## 실행과 검증

Windows 앱은 C# WinForms, Android 앱은 Java와 WebView, 모바일 화면과 오프라인 일정 엔진은 JavaScript로 구현했습니다. 자체 유료 API나 별도 서버 없이 로컬에서 기록하고, 노션 저장에는 인터넷과 노션 계정이 필요합니다.

[빌드·테스트 방법](docs/BUILD.md) · [현재 검증 범위와 한계](docs/VALIDATION.md) · [외부 라이브러리](THIRD_PARTY_NOTICES.md)

개인 기록, 로그인 정보, 앱 서명용 개인 키, 실제 연결 QR과 실행 로그는 이 저장소에 포함하지 않습니다. 저장소에는 소스와 테스트를 올리며, 설치 파일 배포는 별도로 관리합니다.

요구사항과 사용성 판단은 실제 사용 중 발견한 문제를 바탕으로 정했습니다. 구현과 테스트 작성에는 AI의 도움을 받았습니다.
